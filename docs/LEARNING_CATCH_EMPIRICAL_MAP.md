# Learning-catch empirical map

**Document class:** empirical verification (public human neuroscience)  
**Purpose:** refine FSOT organism dynamics toward the moment **new learning sticks** — not LLM token scores.  
**Doctrine:** meaning is actuated through **connective representation + plasticity**; words are a late readout.

---

## Target process (biological)

```text
NOVELTY / ATTEND
    -> ENCODE (successful items show SME markers)
    -> REORGANIZE (insight / schema catch)
    -> SLEEP CONSOLIDATE (NREM spindle-replay spirit)
    -> RETRACE / PROVE (re-access after delay)
    -> ARTICULATE (motor readout of stored meaning)
```

Maps to FSOT stack:

| Human process | FSOT surface (all three languages) |
|---------------|-------------------------------------|
| Novelty / context update | curiosity miss · pending questions · PE spirit |
| Successful encode (SME) | bio-learn oneshot · encode + DA · eng grow |
| Semantic access | retrieve / claim / compose |
| Insight / reorganize | new_concept · mutation · schema edge |
| Offline consolidate | sleep · replay · STDP/consol · LTM spill |
| Articulation | bio-articulate · converse · speak engram |

## Public data classes to refine against

### 1. Subsequent Memory Effect (SME) — encode that will be remembered

| Marker | Direction on successful encode | Use |
|--------|--------------------------------|-----|
| **Theta (θ)** | elevated vs rest / forgotten | encode_open band contrast |
| **Gamma (γ)** | elevated with binding | encode success spirit |
| **Alpha (α)** | often desynchronized | attention during study |

**Literature anchor class:** Sederberg et al. (2003) iEEG SME θ/γ; replications in scalp EEG.  
**In-tree:** `bands.zig` / `smeContrast`, `eeg_gate_anchors_fixed`, speech-EEG doctrine.

**Citation type:** *empirical verification* (directional priors; not free multi-parameter ERP fits).

### 2. ERP process order (novelty → meaning)

| Component | Rough window | Process |
|-----------|--------------|---------|
| **P300 / P3** | ~300 ms | novelty / context update |
| **N400** | ~400 ms | semantic access / mismatch |
| **LPC** | later | re-encoding / decision to retain |

**Use:** ordered phase claims on bio-converse (attend → meaning → motor → self-hear → encode).  
Already claimed as `FSOT_SPEECH_EEG_PHASE_OK` on Phase C.

### 3. Insight / aha (representation catches)

| Marker class | Notes |
|--------------|-------|
| High-frequency / γ bursts | often reported at insight moment |
| Preceding α/θ reorganization | working-memory restructure |
| fMRI network switch | DMN ↔ task-positive (when available) |

**Use:** mutation / new_concept / schema events in think logs as **reorganization proxies**.

### 4. Sleep consolidation

| Stage | Marker spirit | FSOT map |
|-------|---------------|----------|
| NREM | spindles, slow waves, spindle–ripple | sleep_nrem · replay · wet_maint |
| REM | θ / integration | later depth |

**Use:** Phase B sleep retention + think-hour sleep/replay counts.

### 5. Open datasets (downloadable later as feature packs)

| Source family | Modality | Role |
|---------------|----------|------|

**Honesty:** Day-one packaging uses **literature + locked directional priors** (same pattern as Allen class rates). Full multi-GB EDF packs become offline **feature packs** (like MNIST pack), never a server round-trip.
